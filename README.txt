================================================================================
ImageMagick MCPサーバー (v0.1.0)
================================================================================

【概要】
ImageMagick を操作する HTTP ベースの MCP (Model Context Protocol) サーバーです。
クライアントから受け取った描画命令を Redis にキャッシュし、Imagick / ImagickDraw を
用いてプレビュー画像や最終出力用画像の生成を行います。


--------------------------------------------------------------------------------
1. 技術スタック・動作環境
--------------------------------------------------------------------------------
[バックエンド]
- PHP     : 8.4.20-r1 (メイン言語)
- PHP-FPM : 8.4.20-r1 (PHPワーカー)
- Nginx   : 1.28.3-r0 (Webサーバー)
- ImageMagick / Imagick (画像変換・加工処理)
- Redis   (描画命令キャッシュ保存)

[ツール・インフラ]

- Supervisor     : 4.3.0-r0 (プロセス監視・管理)
- Docker / Docker Compose (コンテナ環境)

3. セットアップ・起動手順
--------------------------------------------------------------------------------
【前提条件】
- Docker
- Docker Compose
- Git

【セットアップ手順】
1. リポジトリのクローン
   $ git clone <repository-url>
   $ cd <project-directory>

2. 環境設定ファイルの作成
   $ cp .env.example .env

3. コンテナの起動
   $ docker-compose up -d

4. 依存パッケージのインストール
   $ docker-compose exec app composer install

5. アプリケーション初期化
   $ docker-compose exec app php bin/setup.php

【開発環境での実行】
   $ docker-compose up

【本番環境でのデプロイ】
   $ docker build -t <image-name>:<tag> .
   $ docker push <image-name>:<tag>
   $ docker-compose -f docker-compose.prod.yml up -d

4. 主要機能とAPIエンドポイント
--------------------------------------------------------------------------------
(1) 描画命令の登録
  - エンドポイント: POST /mcp/imagick/transforms
  - 説明: 描画命令列を Redis に保存し、後続処理で参照するキャッシュIDを返却します。
  - リクエスト例:
    {
      "draw": [
        { "method": "setStrokeWidth", [1] },
        { "method": "setStrokeColor", ["#a4610f"] },
        { "method": "arc", [300, 300, 200, 200, 300, 360] }
      ]
    }
  - レスポンス例 (200 OK):
    {
      "id": "imagick:draw:8f3b7f..."
    }

(2) 画像プレビュー生成
  - エンドポイント: POST /mcp/imagick/preview
  - 説明: キャッシュIDをもとにプレビュー用画像を生成します。
  - リクエスト例:
    {
      "id": "imagick:draw:8f3b7f...",
      "canvas": [32, 32],
      "format": "png"
    }
  - レスポンス例 (200 OK):
    {
      "mime": "image/png",
      "blob": "...binary data..."
    }

(3) 画像ダウンロード生成
  - エンドポイント: POST /mcp/imagick/download
  - 説明: キャッシュIDをもとに最終出力用の高解像度または指定フォーマットの画像を生成します。
  - リクエスト例:
    {
      "id": "imagick:draw:8f3b7f...",
      "canvas": [1024, 1024],
      "format": "png"
    }
  - レスポンス例 (200 OK):
    {
      "mime": "image/png",
      "blob": "...binary data..."
    }

--------------------------------------------------------------------------------
6. トラブルシューティング
--------------------------------------------------------------------------------
- コンテナが起動しない (ポート競合)
  -> `docker ps` で確認し、別ポートを使用してください。
- PHPエラー (依存パッケージ不足)
  -> `composer install` を実行してください。
- 権限エラー (ファイルパーミッション)
  -> `chmod` でパーミッションを変更してください。
